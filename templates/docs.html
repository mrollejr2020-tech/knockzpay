Authentication

KnockzPay supports two authentication methods: API Key (simple) and Ed25519 asymmetric signing (hardened production).

API Key (Vault-Locked)

KnockzPay uses **Vault-Locked** security. When you generate a key, we hash it instantly. We only store a hidden fingerprint, never the plain key. This provides **Key Immunity** — even if our database leaks, your secret keys stay safe (**Leak-Proof Security**).

curl -X POST https://api.knockzpay.com/v1/payments \
  -H "X-API-Key: kz_live_your_key" \
  -H "Content-Type: application/json"

Ed25519 Asymmetric (Production)

For high-volume production use. Sign requests with your Ed25519 private key. KnockzPay verifies with your registered public key. Includes replay protection via Redis-backed nonce tracking.

# Required headers for asymmetric auth:
X-Knockz-Merchant-Id: 12345
X-Knockz-Signature:   <base64-ed25519-sig>
X-Knockz-Timestamp:   1714900000
X-Knockz-Nonce:       <unique-uuid>
X-Knockz-Key-ID:      v1

Event Description

Idempotency

All mutation endpoints require an idempotency_key. Retry the same request safely — KnockzPay will return the original response without double-charging.

// Generate per-request
const key = `charge_${userId}_${Date.now()}`;

const txn = await kp.charge({
  amount:          0.01,
  recipient_id:    userId,
  idempotency_key: key   // safe to retry
});

  document.getElementById('unlock-btn').addEventListener('click', async () => {
    // 1. Request KnockzPay Payment
    const receipt = await KnockzPay.requestPayment({
      amount: 5.00,
      recipient: "photo_creator_id",
      description: "Unlock High-Res Photo: Sunset Horizon"
    });

    if (receipt.status === 'settled') {
      // 2. Fetch secure decrypt URL from backend using transaction ID
      const res = await fetch('/api/photo/decrypt', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ txn_id: receipt.transaction_id })

      const data = await res.json();

      if (data.decrypt_url) {
        // 3. Swap source and remove paywall overlay
        document.getElementById('premium-photo').src = data.decrypt_url;
        document.getElementById('paywall-overlay').remove();
      }
    }
  });
</script>
PYTHON / BOTO3 
import boto3
from flask import jsonify, request
from cryptography.fernet import Fernet
import knockzpay

s3_client = boto3.client('s3')
kp = knockzpay.Client(api_key="kz_live_...")

@app.route('/api/photo/decrypt', methods=['POST'])
def decrypt_photo():
    data = request.get_json()
    txn_id = data.get('txn_id')

    # 1. Verify transaction with KnockzPay
    verification = kp.verify_transaction(txn_id)
    if not verification.verified or verification.amount < 5.00:
        return jsonify({"error": "Payment required"}), 402

    # 2. Retrieve encrypted asset from S3
    encrypted_obj = s3_client.get_object(Bucket="knockzpay-vault", Key="photo_abc.enc")
    encrypted_data = encrypted_obj['Body'].read()

    # 3. Decrypt file using key mapped to entitlement
    fernet_key = get_encryption_key("photo_abc") # retrieved securely
    cipher = Fernet(fernet_key)
    decrypted_data = cipher.decrypt(encrypted_data)

    # 4. Generate temporary signed URL or serve stream
    temp_url = save_temporary_decrypted_asset(decrypted_data, expiration=300)
    
    return jsonify({
        "decrypt_url": temp_url
    })
