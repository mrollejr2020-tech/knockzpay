For Developers

Pay-per-use billing
in 5 lines of code.

No complexity. No subscription hell. Just charge what you use, instantly settled, cryptographically verified.

JS SDK 
import KnockzPay from '@knockzpay/sdk';

const kp = new KnockzPay('kz_live_your_key');

// Charge $0.01 for an API call
const txn = await kp.charge({
  user:   userId,
  amount: 0.01,
  action: 'generate_image'
});

console.log(txn.status); // "settled"
console.log(txn.verified); // true
Python SDK 
import knockzpay

kp = knockzpay.Client("kz_live_your_key")

# Charge $0.03 per image generation
txn = kp.payments.create(
    user_id=user_id,
    amount=0.03,
    action="generate_image",
    idempotency_key=request_id
)

assert txn["verified"] == True
cURL 
curl -X POST https://api.knockzpay.com/v1/payments \
  -H "X-API-Key: kz_live_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 0.05,
    "currency": "USD",

  }'
